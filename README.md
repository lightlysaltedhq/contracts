# contracts

Lightly Salted's public contracts. Each package here holds rules and never a brand's values.

- `@lightlysaltedhq/design-foundations`: the design-system contract (tier model, role vocabulary,
  OKLCH derivation, scales, typography). Moving here from the private design-system repository.
- `@lightlysaltedhq/salt-contract`: the platform-neutral Salt contract that Salt for Next.js and
  Salt for WordPress both conform to. To be added.
